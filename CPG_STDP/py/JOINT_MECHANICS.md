# Сустав и динамическая длина мышц

У каждой ноги свой сустав с одной степенью свободы. `muscle_E` и `muscle_F`
остаются разными популяциями: у них отдельные мембранные потенциалы, кальциевая
активация, длина сократительного элемента и сила.

Силы создают момент на суставе. Его угол определяет длину двух
мышечно-сухожильных комплексов: при сгибании сгибатель укорачивается,
разгибатель удлиняется. На движение влияют инерция, демпфирование, упругая
нагрузка, внешний момент и ограничения угла.


## Масштаб и параметры

Клетки мышечного пула рассматриваются как репрезентативные образцы одной
мышцы. Сустав получает **среднюю** силу пула, как и существующая запись
силы в проекте. Увеличение числа образцов само по себе не увеличивает силу
всей мышцы. В MPI сначала суммируются локальные значения, затем результат
делится на глобальный размер популяции, включая процессы без мышечных клеток.

Сустав использует метры/секунды, механизмы мышцы — мм/мс; адаптер выполняет
преобразование. Предельные углы работают как неупругие упоры. Контакт стопы
с опорой, несколько суставов и полноценная модель мышечного веретена пока
не включены. `BWS` сохраняет исходный смысл настройки кожных входов;
механическую нагрузку задаёт отдельный параметр `load_torque_nm`.

Управление через переменные окружения:

| Переменная | Назначение |
|---|---|
| `CPG_JOINT=0` | Контроль с фиксированной длиной комплекса; новая модель мышцы сохраняется |
| `CPG_JOINT_DT_MS` | Шаг обмена с механикой, по умолчанию `0.1` мс, кратен `h.dt=0.025` мс |
| `CPG_IA_SCALE` | Сила синаптического Ia-входа; по умолчанию `0` для контролируемого сравнения |
| `CPG_STEP_NUMBER`, `CPG_TSTOP_MS` | Число шагов и необязательный предел времени симуляции |

Физические параметры сустава задаются значениями по умолчанию в
`JointParameters` (`joint_mechanics.py`) и меняются правкой кода:

| Поле | Назначение |
|---|---|
| `inertia_kg_m2` | Инерция в кг·м² |
| `damping_nm_s` | Демпфирование в Н·м·с/рад |
| `stiffness_nm_rad` | Жёсткость в Н·м/рад |
| `moment_arm_m` | Плечо в метрах |
| `rest_length_m` | Нейтральная длина комплекса в метрах, больше `0.003` |
| `min_angle_rad`, `max_angle_rad` | Пределы угла в радианах, охватывающие ноль |
| `load_torque_nm` | Постоянный момент в Н·м; положительный препятствует сгибанию |

Ia-генераторы реагируют на длину даже при `CPG_IA_SCALE=0`, но их влияние
на CPG выключено. Положительный коэффициент следует настраивать после
проверки изолированной механики. Это упрощённый сенсор длины/скорости.

## Результаты

Для каждой версии сохраняются `joint_left_v0.hdf5`, `joint_right_v0.hdf5`
и соответствующие PNG. HDF5 содержит время, угол, угловую скорость,
длины комплексов и волокон, скорости волокон, отдельные силы E/F и параметры.

Механические данные имеют собственную сетку обмена (`0.1` мс по умолчанию).
На каждом её интервале нейронная модель рассчитывается с удерживаемой длиной;
силы в конце интервала двигают сустав и задают длину следующего интервала.
Это явное раздельное интегрирование. Для исследования проверять сходимость
при уменьшении и электрического шага, и шага обмена.

Структура демпфированной модели Хилла опирается на описание
[Millard/OpenSim](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090555/Millard%2B2012%2BMuscle%2BModels).
